# CGH 入院等待趋势：第一张图

研究期：2024-01-01 至 2026-09-12。数据粒度：一家医院一天的入院等待时间中位数，单位为小时。

## 方法

从已核查的合并底表筛选 CGH，按日期排序并保留完整日历，共 986 天，其中 979 天有等待记录。蓝线直接显示每日 P50；橙线为当日及此前 6 个自然日的每日 P50 等权平均。选择 7 天是为了用一个完整星期的窗口观察较平滑的走势，不是预测模型，也不构成异常阈值。

连续 7 天全部有值才计算均值，共 967 个可用窗口。开头 6 天不计算；2026-08-02 至 08-08 的原始缺失使 7 天线在 08-02 至 08-14 不可用，08-15 恢复。绘图保留 NaN，让折线断开，不填 0、不跨缺口连线。

注意：橙线是每日中位数的平均，不是七天所有患者的平均等待时间或中位数。一个单日尖峰也会影响随后多个重叠窗口，必须与蓝线一起看。

## 读图例子

两段例子为事后选取的教学窗口，不是经过验证的告警规则。

A：2024-05-02 至 2024-05-08，每日 P50 的七日均值为 21.53 小时，此前 04-25 至 05-01 为 11.94 小时。全期最高单日为 2024-05-02，P50 为 29.00 小时；同一周其他日期也多次处于较高水平，因此不只看最高的一天。

| 日期 | 每日 P50（小时） |
|---|---:|
| 2024-05-02 | 29.00 |
| 2024-05-03 | 22.07 |
| 2024-05-04 | 21.22 |
| 2024-05-05 | 14.09 |
| 2024-05-06 | 25.15 |
| 2024-05-07 | 19.02 |
| 2024-05-08 | 20.15 |

B：2024-09-14 的 P50 为 22.75 小时；前一天约 9.77 小时，后一天为 5.42 小时，再后一天约 2.77 小时。这段适合观察局部单日尖峰和随后回落，不能据此排除该日真实的服务压力。

本课仅识别值得继续核查的时间段；尚未结合急诊量、BOR、假期或院内事件判断原因。尚未衡量业务策略采纳、执行或等待改善效果。

## 验证与来源

每日数值已独立重读原始等待 Excel 比对；每个移动窗口均按自然日重新核算，检查了缺失周断点及恢复日期。原件 SHA256 未改变。
